📚 Online Book Store - SQL Data Analysis Project
📌 Project Overview
This project focuses on designing a Relational Database System and solving real-world business queries for an Online Book Store. The database manages comprehensive details across Books, Customers, and Orders to streamline operations and provide actionable insights.

The primary objective of this project is to leverage analytical SQL queries to understand sales trends, customer behavior, and inventory management.

🛠️ Tech Stack
Database: PostgreSQL (SQL)

Tools: pgAdmin 4 

Core Skills: DDL (Data Definition Language), DML (Data Manipulation Language), Joins, Aggregations, Group By

📂 Database Schema
The project consists of three primary tables:

Books: Stores book details, genres, pricing, and current stock levels.

Customers: Contains customer contact information and geographical locations.

Orders: Tracks sales transactions, quantities purchased, and total billing amounts.

🚀 Key Business Problems Solved
I have implemented over 20 analytical queries to address critical business questions, including:

Inventory Tracking: Identifying books with the lowest stock and calculating remaining inventory after fulfilling orders.

Revenue Analysis: Calculating total revenue and evaluating sales performance by genre.

Customer Insights: Identifying top-spending customers and analyzing sales distribution across different cities.

Product Performance: Determining the most frequently ordered books and analyzing top-rated categories like "Fantasy" and "Fiction."

📖 How to Use
Download the SQL Queries.sql file.

Create a new database in your SQL environment (e.g., PostgreSQL).

Run the script to generate the table structures.

Import the provided CSV data files (Books, Customers, Orders) using the COPY command.

Execute the analytical queries to view the results.

📊 Sample Insights
Genre Trends: Comparison of average pricing and total sales within the "Fantasy" genre.

Customer Loyalty: Extracting a list of frequent buyers who have placed two or more orders.
